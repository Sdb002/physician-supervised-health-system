# Food Dataset Schema — `bd_food.csv`

One row per food item. **All nutrient values are per 100 g edible portion**, raw
unless the name says boiled/fried/dried (FCTB's cooked dishes, e.g. "Lentil,
boiled (without salt)", are rows of their own).

> **Current contents: 672 foods** generated by `scripts/convert_datasets.py`
> from `data/food/raw/Bangladeshi_Indian_Foods_Nutrition_700_antioxidants.csv`
> (700 foods compiled from the Food Composition Table for Bangladesh 2013 —
> 381 rows; Indian Food Composition Tables 2017 — 294; USDA SR Legacy — 23;
> literature — 2). Each row's `source` names its table and code.
>
> - `food_id` is `F` + the source file's `No.` (F001–F700), so every food traces
>   back to its source row and to the recipe workbook's `food_no`. The 28 IFCT
>   cultivar rows (Brinjal-1…21, Chillies, green-1…7) are left out — FCTB rows
>   F089/F124 and IFCT's all-varieties mean F288 cover those foods — so the ids
>   have gaps.
> - Blank (not reported) and trace values are stored as 0: a food earns no
>   credit for an unmeasured nutrient. The source has no folate column, so
>   `folate_ug` is 0 for every row.
> - `name_bn` is Bangla script for 406 rows and Roman transliteration for 102;
>   164 rows (mostly IFCT) have no Bangla name and the UI falls back to English.
>
> Do not hand-edit `bd_food.csv` — fix the converter and re-run it, then
> `py scripts/validate_datasets.py`.

## Corrections applied by the converter

Each fixes a source value that is demonstrably wrong. Every changed cell is
listed, with its rule and evidence, in **`corrections_log.csv`** (145 cells).

1. **Wrong-food gap fills reverted** to "not reported". The source filled some
   FCTB gaps from IFCT rows of a *different* food: amaranth stem from amaranth
   seed (iron 9.33 mg in a 92%-water stem), amaranth leaves from amaranth seed,
   drumstick pods from drumstick leaves (vitamin A 17,542 µg — it put 15,352 µg
   RAE per serving into Drumstick Curry), boiled cowpea pods from dried cowpea
   seed, dried lotus seeds from lotus root.
2. **IFCT vitamin A stored as β-carotene** (93 rows). For every IFCT plant row
   the source's "Vit A (µg RAE)" equals its β-carotene-equivalent column — the
   ÷12 retinol-activity conversion was never applied; for 73 rows the stored
   "RAE" would need more β-carotene than the food's total carotenoids, which is
   impossible. FCTB rows are correct. Fixed as RAE = β-carotene eq ÷ 12 (mint
   leaves 4,602 → 384 µg). Dairy rows (khoa, paneer) are left alone.
3. **The same unconverted value in gap fills** (15 rows) — e.g. boiled orange
   sweet potato 5,376 vs 719 µg raw. Fixed from the row's own β-carotene ÷ 12
   where it has one, otherwise the filled value ÷ 12.
4. **Cited replacements** for blank or garbled rows: spinach, raw and chicken
   breast minerals (USDA FoodData Central 168462 / 171077 — blank here, and
   garbled in the previous FCT-BD export: spinach iron 52 mg and phosphorus
   471 mg, chicken iron 32 mg and magnesium 173 mg); bay leaf (every mineral
   was 1, a placeholder — FCTB 07_0001 values = USDA SR 02004); dried lotus
   seed sodium (13,705 mg → 5 mg, USDA FDC 170149); amaranth leaf vitamin A
   (146 µg RAE, USDA FDC 168385).
5. **Missing energy** computed with FCTB's own formula (4 × protein + 9 × fat +
   4 × carbohydrate + 2 × fibre) for 8 IFCT oils (900 kcal) and nigella seed.
   Five USDA dried herbs (marjoram, oregano, rosemary, sage, thyme) have no
   macros in the source and stay at 0 kcal; the ranking treats an item with
   no recorded energy as having no density score.

*History:* versions v0.1–v0.3 (2026-07) held 250 foods from an earlier
FCT-BD 2013 export, including a manual iron/calcium fix for chicken breast and
spinach. That dataset was retired on 2026-10-08; the fix is now correction 4.

## Columns

| Column | Type | Unit | Description |
|---|---|---|---|
| `food_id` | string | — | Unique ID, `F` + source No. Referenced by `data/recipe/recipe_ingredients.csv`. |
| `name_en` | string | — | English name. |
| `name_bn` | string | — | Bangla name (UTF-8 script, else Roman transliteration). |
| `food_group` | string | — | One of: `grain`, `legume`, `vegetable`, `fruit`, `fish`, `meat`, `egg`, `dairy`, `oil`, `sweet`, `spice`, `other`. |
| `kcal` | float | kcal | Energy. |
| `protein_g` | float | g | Protein. |
| `carb_g` | float | g | Available carbohydrate (FCTB convention: fibre is not included). |
| `fat_g` | float | g | Total fat. |
| `fiber_g` | float | g | Dietary fiber. |
| `iron_mg` | float | mg | Iron. |
| `calcium_mg` | float | mg | Calcium. |
| `zinc_mg` | float | mg | Zinc. |
| `folate_ug` | float | µg | Folate (DFE) — not in the source, 0 for every row. |
| `vit_a_ug` | float | µg RAE | Vitamin A. |
| `vit_c_mg` | float | mg | Vitamin C. |
| `sodium_mg` | float | mg | Sodium. |
| `potassium_mg` | float | mg | Potassium. |
| `tags` | string | — | `\|`-separated flags used by the matcher and the contraindication gate, e.g. `iron_rich\|high_sodium`. Vocabulary listed below. |
| `source` | string | — | Source table and code, plus any cited correction. |

Category → `food_group`: Leafy Vegetables and Roots & Tubers → `vegetable`;
Nuts & Seeds and Beverages → `other`; in Sugars & Miscellaneous only sugar,
honey, jaggery and sugarcane juice are `sweet` (salt, baking powder, betel
leaves, toddy → `other`).

## Tag vocabulary

`staple`, `high_protein`, `lean`, `high_fiber`, `iron_rich`, `calcium_rich`,
`potassium_rich`, `leafy_green`, `fruit`, `dairy`, `probiotic`, `omega3`,
`oil`, `high_fat`, `high_sugar`, `high_sodium`, `dessert`, `added_sugar`,
`brewed_beverage`, `bangladeshi`.

Tags are derived by the converter (thresholds in its docstring), not
hand-curated. Three have specific consumers:

- `bangladeshi` — listed in FCTB 2013 or used in a household recipe (400
  rows). Only these are recommended on their own — top foods and the meal
  plan (`src/diet/food_db.py`, `recommendable_foods`); the IFCT/USDA rows were
  compiled to fill nutrient gaps and include foods rarely eaten in Bangladesh
  (Indian millets, marine fish, offal). Every row still supplies recipe
  nutrients and stays selectable in the physician's plan editor. Top foods
  also leave out the spice group and `brewed_beverage` items, which are used
  by the gram (`eaten_in_portions`).

- `added_sugar` — the foods the recipe workbook classes as added sugar (sugar,
  honey, jaggery ×3, sweetened condensed milk). A recipe whose added sugar
  supplies >10% of its energy inherits `high_sugar` (WHO 2015).
- `brewed_beverage` — tea and coffee *powder*, dry concentrates brewed from a
  few grams; the recommender penalizes them like spices.

`high_sodium`, `high_sugar`, `high_fat` are **exclusion tags** referenced by
`data/reference/contraindications.yaml` — the contraindication gate removes
foods carrying an excluded tag for the patient's conditions. Add new tags
freely, but register exclusion tags in that YAML.

No rule excludes on `high_fat`: it is total fat, which also marks nuts,
oilseeds and oily fish. High cholesterol excludes `solid_fat` instead —
butter, ghee, vanaspati, margarine, coconut oil and palm oil. That tag, like
`liver` and the `contains_*` tags of the dietary restrictions, is not stored
in the CSV: it is read off each food's name and group when the table is loaded
(`src/diet/restriction_tags.py`).

## Validation rules (enforced by `scripts/validate_datasets.py`)

- `food_id` unique, matches `F\d+`.
- All nutrient columns numeric and ≥ 0; `kcal` ≤ 900.
- `food_group` from the list above.
- Every tag from the vocabulary above (warns on unknown tags).
- `source` present on every row.
