# Exercise Dataset Schema — `exercises.csv`

One row per exercise, generated by `scripts/convert_datasets.py` from
`raw/exercise_safety_dataset.csv` (408 exercises from 88 cited sources: NHS
pages and trust leaflets, AAOS OrthoInfo, the US National Institute on Aging,
ACE, the Otago programme, the 2024 Compendium of Physical Activities...) and
`data/reference/exercise_met.yaml` (the Compendium MET of each exercise that
has one). Never hand-edit this file: fix the converter, which documents every
decision, then run `scripts/validate_datasets.py`.

Used by `src/lifestyle/` to build the FITT-VP prescription: the safety gate
reads `contra_tags`, the ranking reads the levels, equipment and `traits`, and
the plan shows the dose, method, easier version, the notes for the patient's
conditions and the video.

## Columns

| Column | Description |
|---|---|
| `exercise_id` | The source id, `EX` + three digits (EX001-EX469; the source's own gaps are kept). |
| `name_en`, `name_bn` | Name. The source has no Bangla names: `name_bn` is empty and the app shows the English name. |
| `category` | `aerobic`, `strength`, `flexibility`, `balance` or `breathing` (see below). |
| `exercise_type` | The source's own type: aerobic/cardio, strength, pelvic floor, flexibility/stretching, mobility/range-of-motion, balance, breathing/relaxation. |
| `body_region`, `muscles` | Primary body region (13 values) and muscles. |
| `fitness_level` | `beginner`, `intermediate` or `advanced`. |
| `met_value`, `met_code` | 2024 Compendium MET and activity code; empty when the Compendium has none (every non-aerobic row but one, and nine aerobic warm-up drills). |
| `intensity_level` | `light` (< 3 MET), `moderate` (3-5.9) or `vigorous` (>= 6); empty with no MET. |
| `equipment`, `needs_equipment` | What it is done with (`chair`, `mat`, `household item (towel)`, `dumbbells`...) and whether that has to be bought (`yes`/`no`). |
| `setting` | `home`, `gym` or `home or gym`. |
| `sex` | `both`, `female` or `male`. |
| `older_adult` | `yes`, `modify` (suitable with the easier version) or `no`. |
| `contra_tags` | `\|`-separated tags the safety gate excludes on (vocabulary below). |
| `traits` | `\|`-separated traits the ranking reads (vocabulary below). |
| `modify_for` | The conditions the source rates "modify": the plan shows that condition's note to a patient who has it. |
| `note_general`, `note_pregnancy`, `note_hypertension`, `note_diabetes`, `note_anemia`, `note_knee_osteoarthritis` | The source's `condition_reasons`, one note per condition. |
| `injury_avoid`, `injury_modify` | Body regions the source rates avoid / modify with an injury there. Not used yet: the patient record has no injuries. |
| `dose`, `how_to`, `easier_version`, `safety_notes`, `sex_note` | As the source gives them. |
| `source`, `source_url`, `source_detail`, `evidence_basis` | The citation; `source_detail` says whether the source gives instructions and dose, instructions only, or only names the exercise. |
| `video_url`, `video_title`, `video_channel`, `video_match`, `video_note` | A demonstration video and how closely it matches (`exact`, `close variant`, `none`). |

## Category

| Source type | `category` | |
|---|---|---|
| aerobic/cardio | `aerobic` | Planned as the week's aerobic activity only with a MET (its minutes are counted). |
| strength, pelvic floor | `strength` | Pelvic floor training is resistance training of those muscles (NHS). |
| flexibility/stretching, mobility/range-of-motion | `flexibility` | ACSM's flexibility component is range of motion. |
| balance | `balance` | ACSM's neuromotor component; planned for adults 65 and over (WHO 2020). |
| breathing/relaxation | `breathing` | Kept in the table, not planned. |

## Contra-tag vocabulary

| Tag | Set when | Excluded for |
|---|---|---|
| `avoid_pregnancy`, `avoid_hypertension`, `avoid_diabetes`, `avoid_anemia`, `avoid_knee_osteoarthritis` | the source rates that condition "avoid" | that condition |
| `supine_position` | the pregnancy note says the exercise is done lying on the back | pregnancy |
| `not_for_older_adults` | `older_adult_suitable` = no | patients 65 and over |
| `female_only`, `male_only` | `sex_suitability` | men / women |

The conditions' rules are in `data/reference/contraindications.yaml`
(`conditions`), the age and sex rules in the same file (`populations`).

## Trait vocabulary

`pelvic_floor`, `pregnancy_recommended`, `knee_oa_strengthening`,
`high_impact`, `low_impact`, `post_meal`, `isometric_hold`,
`falls_prevention`, `seated`. Each is derived from a column or the wording of
a note; the rules are in the docstring of `scripts/convert_datasets.py`.

## Validation rules

- `exercise_id` unique, matches `EX\d{3}`.
- `category`, `fitness_level`, `setting`, `sex`, `older_adult` from their lists.
- `met_value` numeric in (0, 20] where present, `intensity_level` its band;
  no MET, no intensity.
- Every tag and trait from its vocabulary; every condition in `modify_for`
  has a note.
